# 振动信号处理与分析

Python 桌面程序，使用 Tkinter、NumPy、SciPy 和 Matplotlib。

在项目目录执行 `python -m pip install -r requirements.txt`，然后执行 `python app.py`，或双击 start.bat。建议使用 Python 3.10 及以上版本，Anaconda 环境可直接运行。

## 操作

1. 在“信号生成”页设置双频正弦、高频干扰、噪声和可选脉冲，点击“生成并分析”。随机种子固定时信号可复现。
2. 外部数据在“CSV 导入”页载入。支持 UTF-8（含 BOM）、英文逗号分隔、一行可选表头。幅值列从 1 开始。单列数据设置时间列为 0 并填写采样率。时间列存在时填写其列号，时间单位为秒，程序检查等间隔并推算采样率。
3. 在“预处理与滤波”页选择去均值和滤波方法，点击“按当前滤波参数重新分析”。所有方法都从同一份原始数据重新计算。
4. 切换四个绘图页和指标页观察结果。图下工具栏支持缩放、平移和图片保存。
5. 点击“保存结果”，选择父目录。每次创建独立 result_时间戳 子目录，包含 waveform.csv、spectrum.csv、metrics.csv、parameters.txt。

修改数据参数后需要重新生成或导入。修改滤波参数后需要重新分析，旧图与指标会清空，保存按钮禁用。后台计算期间修改参数会使该次计算结果失效。操作错误在状态栏和弹窗中显示。

## 计算定义

- 标准差为总体标准差（ddof=0），RMS 为原始或处理后数据的均方根。
- 峭度为中心四阶矩除以方差平方，高斯信号理论值为 3。常量信号的峭度未定义。
- 波形因子为 RMS / 平均绝对值，零信号时未定义。未定义值在界面显示 —，CSV 使用 nan。
- FFT 采用矩形窗，无补零。单边峰值幅度为 abs(FFT)/N，正频率乘 2，直流与偶数长度的奈奎斯特频点保持原值。非整周期信号会出现频谱泄漏。
- 主频为排除直流后最大幅值对应的 FFT 频点，不作插值。分辨率为 fs/N。零信号主频未定义。
- Butterworth 低通使用 SOS 双向滤波，零相位，总幅频响应为单向响应的平方。因此设置截止频率处双向幅度约为 0.5，阶数填写单向设计阶数。
- 移动平均和中值滤波均采用居中奇数窗口、反射边界。窗口上限为 1001 点且不得超过样本数。低通阶数范围为 1～12。
- 单次数据限制为 4～1,000,000 点，幅值绝对值不超过 1e50。大数据时域绘图最多抽取 20000 点，计算和导出保留全部样本。
- 合成信号相位为零。脉冲独立按每点概率加入，随机正负号。时长转换为 round(fs×时长) 个样本，实际记录时长在参数文件保存。

## 文件复用

waveform.csv 的列为 time_s、raw、processed。重新导入时，时间列填 1，幅值列填 2 或 3。spectrum.csv 保存原始与处理后单边峰值幅度。metrics.csv 保存九项指标。parameters.txt 保存采样率、样本数、数据来源、生成参数、处理参数及计算定义。

运行 `python -m unittest discover -s tests -v` 验证数值计算、输入校验和导出。
