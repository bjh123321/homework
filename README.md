# 振动信号虚拟仪器：生成、滤波与多域分析

本项目是《虚拟仪器与信号处理》课程设计的精简实现。程序使用 Python、Tkinter 和 Matplotlib 构建桌面虚拟仪器，支持仿真信号生成、单通道 CSV 导入、数字滤波、时域/频域/时频分析及实验数据导出。

**无需下载 XJTU-SY 等大型数据集，无需真实传感器或采集卡。** 默认实验使用程序生成的可重复仿真信号。若已有小型 CSV 测试数据，也可以导入分析。

## 1. 功能

1. **信号输入**：生成双频振动信号、高频干扰和高斯白噪声；也可导入单通道 CSV。
2. **预处理**：去均值、线性去趋势。
3. **数字滤波**：Butterworth 低通、移动平均、中值滤波，以及不滤波对照。
4. **时域分析**：均值、总体标准差、RMS、绝对峰值、峰峰值、峭度、波形因子。
5. **频域分析**：FFT 单边峰值幅值谱、主频识别、Welch 功率谱密度。
6. **时频分析**：短时傅里叶变换（STFT）。
7. **显示与保存**：显示原始/处理后波形、频谱、功率谱、时频图和指标；导出 CSV 与参数说明文件。

## 4. 默认仿真实验

默认采样率为 2000 Hz，时长为 2 s，共 4000 个采样点。信号模型为：

```
x(t) = 1.0 sin(2π·50t)
     + 0.5 sin(2π·120t)
     + 0.3 sin(2π·400t)
     + n(t)
```

其中，50 Hz 和 120 Hz 为有效分量，400 Hz 为高频干扰，n(t) 为标准差 0.2 的零均值高斯白噪声。随机种子默认为 42，因此默认仿真可重复生成。

建议按以下步骤完成课程实验：

1. 在“信号生成”页保留默认参数，点击“生成并分析”，得到原始信号。
2. 在“预处理与滤波”页选择“不滤波”，记录原始波形、指标和频谱。
3. 选择 Butterworth 低通，截止频率设为 180 Hz、阶数设为 4，重新分析并观察 400 Hz 分量的衰减及有效分量的保留情况。
4. 分别选择移动平均和中值滤波，窗口点数设为 11，与低通结果进行比较。
5. 查看 FFT、Welch PSD 和 STFT，比较各频率分量及其时频分布。
6. 点击“保存全部结果”，将本次实验数据保存到独立结果目录。

不要仅凭波形是否平滑判断算法优劣。应结合有效分量保留、干扰抑制、时域指标和频谱变化进行分析。默认 180 Hz 截止频率只用于本项目给定的低频仿真信号，不应未经分析直接用于其他频带的实测信号。

## 5. CSV 导入说明

程序支持 UTF-8 或 UTF-8 BOM 编码、逗号分隔的单通道 CSV，可包含一行表头。

- 幅值列编号从 1 开始。
- 没有时间列时，将“时间列”设为 0，并填写采样率。
- 有时间列时，填写时间列编号；时间单位必须为秒，且时间戳严格递增、等间隔。程序根据时间间隔计算采样率。
- 记录至少包含 4 个有效样本，单次数据最多 1,000,000 个样本。

导出的 `waveform.csv` 包含时间、原始信号和处理后信号三列。重新导入该文件时，可将时间列设为 1，幅值列设为 2（原始）或 3（处理后）。

## 6. 算法说明

- **去趋势/去均值**：可分别启用线性去趋势和去均值。
- **Butterworth 低通**：使用二阶节（SOS）结构和前后向滤波，避免相位延迟；截止频率必须小于 Nyquist 频率，滤波阶数为 1～12。
- **移动平均/中值滤波**：使用居中奇数窗口和反射边界，窗口点数不得超过 1001。
- **时域指标**：标准差采用总体定义（ddof=0）；峭度为中心四阶矩除以方差平方，高斯信号理论值为 3；波形因子为 RMS/平均绝对值。
- **FFT**：采用矩形窗、不补零，输出单边峰值幅值谱；频率分辨率为 fs/N。主频取排除直流后的最大幅值频点，不作插值。
- **Welch PSD**：采用 Hann 窗，分段长度最多 1024 点，50% 重叠，输出功率谱密度。
- **STFT**：采用 Hann 窗，窗长最多 256 点，75% 重叠，输出局部幅值随时间和频率的变化。

## 7. 结果文件

每次保存会在用户选择的目录下创建新的 `result_时间戳` 文件夹，不覆盖已有实验。文件包括：

| 文件 | 内容 |
|---|---|
| `waveform.csv` | 时间、原始信号、处理后信号 |
| `spectrum.csv` | FFT 频率轴及原始/处理后单边幅值 |
| `psd.csv` | Welch 频率轴及原始/处理后功率谱密度 |
| `stft.csv` | STFT 时间、频率及原始/处理后幅值 |
| `metrics.csv` | 原始与处理后特征指标 |
| `parameters.txt` | 采样率、样本数、数据来源、处理参数和算法定义 |
