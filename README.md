# 基于 Python 的振动信号采集、滤波与频谱分析虚拟仪器

本项目是《虚拟仪器与信号处理》课程设计程序。软件使用 Python 桌面 GUI，完成信号仿真生成或 CSV 导入、预处理、数字滤波、时域/频域/时频分析以及结果保存。

> 说明：当前程序没有连接真实采集卡或传感器。数据输入通过可复现的仿真信号和用户提供的 CSV 文件实现，不应将其描述为真实硬件实时采集。

## 1. 功能

- **数据输入**：生成含 50 Hz、120 Hz 有效分量、400 Hz 干扰和高斯噪声的测试信号；或导入单通道 CSV。
- **预处理**：去均值、线性去趋势。
- **数字滤波**：Butterworth 低通、移动平均、中值滤波，或不滤波对照。
- **时域指标**：均值、总体标准差、RMS、绝对峰值、峰峰值、峭度、波形因子。
- **频域分析**：FFT 单边峰值幅值谱、主频识别、Welch 功率谱密度。
- **时频分析**：短时傅里叶变换（STFT）。
- **结果导出**：原始/处理后波形、FFT、PSD、STFT、指标和参数分别保存为 CSV/TXT。

轴承全寿命监测和 XJTU-SY 批处理脚本是仓库中保留的历史扩展代码，不属于本课程精简版的默认运行流程。运行本课程项目不需要下载 5 GB 数据集，也不需要先创建 SQLite 数据库。

## 2. 环境安装

建议 Python 3.10 或更高版本。Windows Anaconda、Miniconda 或普通 Python 环境均可。

在项目目录打开 PowerShell：

    python -m pip install -r requirements.txt

## 3. 启动

    python app.py

也可以在 Windows 中双击 start.bat。启动后使用桌面程序完成课程实验。

## 4. 软件操作

1. **信号生成**：默认采样率 2000 Hz、时长 2 s；有效分量为 50 Hz 和 120 Hz，另含 400 Hz 干扰及标准差 0.2 的高斯噪声。随机种子默认为 42，便于复现实验。点击“生成并分析”。
2. **CSV 导入**：选择单通道 CSV。幅值列编号从 1 开始；若文件没有时间列，将“时间列”设为 0 并填写采样率；若有以秒为单位的等间隔时间列，填写该列编号，程序将根据时间间隔计算采样率。支持 UTF-8/UTF-8 BOM、逗号分隔及一行表头。
3. **预处理与滤波**：选择是否去均值、是否线性去趋势，以及不滤波、Butterworth 低通、移动平均或中值滤波。低通截止频率必须小于 Nyquist 频率；移动平均和中值滤波窗口必须为不超过 1001 的奇数。
4. **查看结果**：依次查看原始波形、处理后波形、波形对比、FFT 幅值谱、Welch 功率谱、STFT 时频图和分析指标。图形下方工具栏可缩放、平移及单独保存当前图。
5. **保存结果**：点击“保存全部结果”，选择父目录。程序会新建独立的 result_时间戳 文件夹，不覆盖以前的实验。

## 5. 默认实验参数与复现建议

默认输入模型为：

    x(t) = 1.0 sin(2π·50t) + 0.5 sin(2π·120t)
           + 0.3 sin(2π·400t) + n(t)

其中 n(t) 为标准差 0.2 的零均值高斯白噪声。采样率 2000 Hz，记录时长 2 s，共 4000 点。默认滤波为四阶 Butterworth 低通，截止频率 180 Hz，采用前后向 SOS 滤波。

建议完成以下对照：
- 不滤波：观察 50 Hz、120 Hz、400 Hz 分量及噪声。
- Butterworth 低通：比较 400 Hz 干扰衰减和 50/120 Hz 有效分量保留情况。
- 移动平均、中值滤波：比较平滑效果以及对有效分量幅值的影响。
- 去趋势：可在导入含线性漂移的 CSV 后启用，比较处理前后的波形均值和趋势。

不要仅凭波形“看起来更平滑”评价滤波效果；应同时比较有效频率分量幅值、噪声/干扰衰减和时域指标。180 Hz 低通参数适用于本项目的低频合成示例，不适用于未经分析便直接处理高频轴承共振或包络信号。

## 6. 算法与参数定义

- 标准差使用总体定义（ddof=0）；RMS 为均方根；峭度为中心四阶矩除以方差平方，高斯信号理论值为 3；波形因子为 RMS/平均绝对值。
- FFT 使用矩形窗、不补零，输出单边峰值幅度谱；直流和偶数长度的 Nyquist 点不乘 2。频率分辨率为 fs/N，主频取排除直流后的最大幅值频点，不作插值。
- Butterworth 低通使用 SOS 双向滤波，零相位；截止频率处的双向幅度响应不同于单向滤波器。
- Welch PSD 使用 Hann 窗、最多 1024 点分段、50% 重叠，输出功率谱密度。
- STFT 使用 Hann 窗、最多 256 点窗长、75% 重叠；短记录自动缩短窗长。
- 移动平均和中值滤波采用居中奇数窗口及反射边界。
- 单次信号限制为 4 至 1,000,000 点；超过 20,000 点时仅对时域图抽样显示，计算与导出保留完整数据。

## 7. 结果文件

每次保存生成一个新的结果目录，包含：

| 文件 | 内容 |
|---|---|
| waveform.csv | 时间、原始信号、处理后信号 |
| spectrum.csv | FFT 频率轴、原始及处理后单边幅值 |
| psd.csv | Welch 频率轴、原始及处理后 PSD |
| stft.csv | STFT 时间、频率、原始及处理后幅值 |
| metrics.csv | 原始与处理后时域/频域指标 |
| parameters.txt | 采样率、数据来源、滤波参数和算法定义 |

## 8. 自动化测试

安装依赖后运行：

    python -m unittest discover -s tests -v

测试覆盖信号生成可复现性、FFT 幅值、时域指标、低通抑制、移动平均和中值滤波、CSV 输入校验、Welch/STFT 输出及结果导出。
